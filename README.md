# E0 Equation Solver v0.2

> **О проекте:** Этот репозиторий создан как демонстрационный пет-проект для технических собеседований. На протяжении всей карьеры я работал исключительно над закрытыми коммерческими продуктами, поэтому у меня не было публичного кода, который можно было бы открыто показать на GitHub.

**Демо:** [aleksandrtestaccount.github.io/demo](https://aleksandrtestaccount.github.io/demo-interval-solver/)

В проекте используются Vue 3 (Composition API), сборщик Vite и Web Workers. Для подсветки синтаксиса применяется пакет `shiki`.

## Локальный запуск и разработка

### Протестировано на

- Node.js `22.22.1`
- npm `9.2.0`

### Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск локального dev-сервера
npm run dev
```

### Сборка и проверка качества кода

```bash
# Сборка продакшен-версии (в папку dist/)
npm run build

# Локальный предпросмотр собранного проекта
npm run preview

# Проверка и автоисправление ошибок линтером ESLint
npm run lint

# Форматирование исходного кода через Prettier
npm run format
```

## Солвер

Солвер изолирован от процесса сборки Vite и располагается в `public/libs/mainBundle.min.js`. Это мой личный проект — чтобы открыть его исходники, мне сначала нужно их отрефакторить.
