Enter an equation in the editor, for example x + x = 4, then press the "Solve" button. You must specify the number of bits allocated for each number, e.g., for an 8-bit number: size 8 0.

For calculations involving fractions, specify both the number of fractional and integer bits: 

size 5 1; x + x = 7;

If you encounter the error message "Invalid number", try to increase the number of bits: 

size 11 0; x + x = 1024

Adding a '+' to 'size' ensures that all calculated values will be non-negative: 

size + 8 0

This solver is based on interval arithmetic combined with a simple backtracking search for boolean variables. It is generally slow and performs even worse with modular arithmetic and bitwise operations. This project was created exclusively for educational purposes.

E0 has no standard loops (like for or while) or classic imperative branching. Instead of step-by-step instructions, you describe the problem using declarative equations and constraints.

A template-style preprocessor is planned for upcoming releases. It will automate repetitive patterns and generate boilerplate constraints dynamically at compile time.
