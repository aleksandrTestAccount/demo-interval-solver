The conditional construct works exclusively with numbers, and the conditional expression itself must evaluate to a boolean type.

Simple conditional equations look like this:

b ? n1 : n2 = r 
r = b ? n1 : n2

Parentheses are strictly required for nesting or grouping complex expressions inside a conditional construct: 

(x * x) = (b1 || b2) ? (a + v) : v

Please note that the ? and : tokens are heavily overloaded depending on the context, so use parentheses to avoid ambiguity: 

// Conditional construct: b ? x : v 
// Bit extraction: x : n
// Implication-like operation: b ? x
