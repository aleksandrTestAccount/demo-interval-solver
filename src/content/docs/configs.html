Engine configuration parameters allow you to fine-tune compilation limits, execution flags, and variable strictness.

For example, you can handle large numbers by increasing the size, or bypass the solving stage entirely to just validate the code structure: 

size 101 0

a * b = 1267650600228229401496703205376

a < 2 ** 50

// Check if code is valid without solving
config solve false

Enabling strict mode throws immediate errors for variables that are not explicitly typed beforehand: 

config strict true

// error
x > y == b

To pass strict mode, encapsulate variable names inside numbers or booleans declaration blocks: 

config strict true

numbers {
    x, y,
}

booleans {
    b,
}

// ok
x > y == b
