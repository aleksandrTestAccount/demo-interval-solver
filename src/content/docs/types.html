Supported types: only booleans and numbers.

//a,b,c - boolean type vars
a == true
b == false
1 > 2 == c 
size 4 0
//result: {a: true, b: false, c: false}

c == true
1 > 2 == c 
size 4 0
//result: false

Numbers can be represented in binary, hexadecimal, octal, and decimal formats: 

a1 = 0b101.1 // 5.5 in decimal
a2 = 0xB.A   // 11.625 in decimal
a3 = 0o13.3  // 11.375 in decimal
a4 = 0d12.34 // 12.34 in decimal (precision loss due to binary conversion)

Note on leading zeros:

/*
    leading zeros:
    001 = x    // error
    0b001 = x  // ok
    05 = x     // error
    0d05 = x   // ok
*/

Data types are inferred by operators. For example, all variables in arithmetic equations (such as a + b = r) are numbers, while variables in boolean equations (such as x1 || x2 == x3) are booleans. The == operator acts as the equality operator for the boolean type.
