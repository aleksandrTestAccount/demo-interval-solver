The classic 0-1 Knapsack problem where items have predefined weights and values. The objective is to maximize value without exceeding total weight capacity. 

// Item Weight Value
//   x0      3    53 
//   x1      7    41
//   x2      3    10
//   x3      4    35
//   x4      5    71
//   x5      9    67

// total weight <= 20
// maximize total value
// each item may be included at most once.

// x0, x1, x2, x3, x4, x5 - boolean values
// *? - multiplication by boolean value operator
// 5 *? true = 5
// 5 *? false = 0

(3 *? x0)  + (7 *? x1)  + (3 *? x2)  + (4 *? x3)  + (5 *? x4)  + (9 *? x5) = weight
(53 *? x0)  + (41 *? x1)  + (10 *? x2)  + (35 *? x3)  + (71 *? x4)  + (67 *? x5) = value
