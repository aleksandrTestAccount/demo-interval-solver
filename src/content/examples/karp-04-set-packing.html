Karp's 4th NP-complete problem: Set Packing. Finds a collection of k = 3 mutual disjoint subsets from a universal block list by treating all overlapping subsets as invalid logic pairings. 

/* Sets:
    u : {1,2,3,4,5,6,7,8}
    a : {1,2,3} 
    b : {4,5,6} 
    c : {1,4,7} 
    d : {2,5,8} 
    e : {3,6,8} 
    f : {7,8} 
*/

// k = 3 
3 = sumBool( a, b, c, d, e, f)

// Each intersection of sets introduces an additional constraint.
a && c == false
a && d == false
a && e == false

b && c == false
b && d == false
b && e == false

c && f == false

d && e == false
d && f == false

e && f == false
