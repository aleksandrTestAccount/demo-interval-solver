Weighted Partial MaxSAT problem where some hard clauses must be strictly satisfied while soft clauses carry varying weights to maximize. 

// clause             : weight

//  x0 ||  x1         : 1
//  x0 || !x1         : must be satisfied
// !x0 ||  x1 ||  x2  : 2
// !x0 || !x1 || !x2  : must be satisfied
// !x1 || !x2         : 3
//  x0 || !x2         : 1
// !x0 ||  x1 || !x2  : 1
//  x0 ||  x1 ||  x2  : 2
// !x0 ||  x1         : 2
// !x0 || !x1         : 3

 x0 ||  x1         == b0;  b0 ? 1 : 0 = v0
 x0 || !x1         == true 
!x0 ||  x1 ||  x2  == b2;  b2 ? 2 : 0 = v2
!x0 || !x1 || !x2  == true
!x1 || !x2         == b4;  b4 ? 3 : 0 = v4

 x0 ||  x1 ||  x2  == b7;  b7 ? 2 : 0 = v7
!x0 ||  x1         == b8;  b8 ? 2 : 0 = v8
!x0 || !x1         == b9;  b9 ? 3 : 0 = v9
