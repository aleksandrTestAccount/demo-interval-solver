Travelling Salesman Problem (TSP) edge matrix script generator. It translates direct nested object lists mapping node boundaries into fully structured Hamiltonian cycle bounds. 

generate {
    name: tsp,
    max: 20,
    edges: {
        v1: {
            v2: 2,
            v3: 6,
        },
        v2: {
            v3: 3,
        }
    }
}
