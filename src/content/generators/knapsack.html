A generator setup producing complete low-level E0 equation sets for a 0-1 Knapsack matrix based on structural arrays of item values and weights. 

generate {
    name: knapsack,
    maxWeight: 20,
    maxNumber: 300,
    items: [
        {w: 3, v: 53},
        {w: 7, v: 41},   
        {w: 3, v: 10},
        {w: 4, v: 35},
        {w: 5, v: 71},
        {w: 9, v: 67},
    ],
}
